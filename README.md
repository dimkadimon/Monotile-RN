# Monotile-RN

Code and data for **"Towards Strongly Aperiodic Monotiles in Higher Dimensions"** (D. Kamenetsky, 2026).

📄 **Paper:** [arXiv:2610.00916](https://arxiv.org/abs/2610.00916) · [PDF](https://arxiv.org/pdf/2610.00916) · Typst and LaTeX sources in [`paper/`](paper/)

A frame-marking formalism for the N-dimensional chair rep-tile C_N = [0,2]^N \ (1,2]^N: the marked tile is C_N with its
orientation frame, the matching rule is the contact language generated by the substitution, closed under coarsening.
A finite certificate (closure, tightness, two-shell enclosure analysis) implies unique hierarchy and hence strong aperiodicity.

* **N = 3**: the certificate passes (Theorem A) and reproduces the Chair44 statistics 2388 → 44 (30 occurring) → 33 → 15 → 1
  independently of the published rule sets. Among 2187 homochiral frame assignments exactly 3 (one conjugacy orbit) close (Theorem B).
* **N = 4**: canonical, D4-, Z2xZ2-, Z4-symmetric families and a lift of the 3D solution fail closure; the remaining finite problem is stated.

## Quick start (Python 3; NumPy only for figures)

```bash
# Theorem A (about 2 s): closure, tightness, enclosure certificate for N=3
python3 cert6.py 3 trivial N3 "{'0':(0,1,2),(0,0,0):(0,1,2),(0,0,1):(0,2,1),(0,1,0):(2,1,0),(0,1,1):(1,2,0),(1,0,0):(1,0,2),(1,0,1):(0,1,2),(1,1,0):(2,0,1)}" noprop

# Theorem B: scan all 2187 homochiral N=3 assignments (~5 min), then full closure test (~20 min)
python3 scan3.py 3 scan3.pkl
python3 closure_scan3.py

# N = 4: canonical assignment (fails closure); Gamma-invariant families
python3 cert6.py 4 trivial N4canon
python3 symsearch4.py "[(1,2,3,0),(2,1,0,3)]" D4
python3 symsearch4.py "[(3,1,2,0),(0,2,1,3)]" G22
```

## Files

| file | content |
|---|---|
| `chairN.py` | geometry of C_N, substitution with frame assignment, poses, contacts, facet triples |
| `cert3.py` | hierarchical language (least fixed point), facet rules, tightness, `Rules` helper |
| `cert6.py` | the certificate: coarsening closure (C1), tightness (C2), enclosure analysis (C3) |
| `scan3.py`, `closure_scan3.py` | Theorem B |
| `symsearch4.py` | N=4 searches over conjugation-invariant assignments |
| `search4.py`, `search4b.py`, `lift.py`, `bobj.py`, `colour.py` | other N=4 attempts reported in the paper (all negative) |
| `cert6_N3triv.pkl` | certified N=3 data: the 44 poses P*, the 135 facet triples F*, statistics |
| `closure_scan3.pkl`, `scan3.pkl` | Theorem B data |
| `paper/` | Typst source of the paper; `figures/` figures |
| `cert4.py`, `prop.py`, `closure.py` | earlier, superseded variants kept for reference |

Pose convention: cubes of the reference tile are centred at 2u+1 (u in {0,1}^N minus (1,..,1)); a pose (g,t) with g a signed
permutation (`(perm, signs)`, `apply(g,x)_i = signs[i]*x[perm[i]]`) and t an integer vector places cubes at g(2u+1)+2t.
